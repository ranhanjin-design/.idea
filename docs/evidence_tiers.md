# PawPlan HK 证据层级与验收标准

对照 Project Briefing：官方事实硬过滤，场地自有规则作条件，社区目录只作提示。

## 1. 证据层级

| Tier | 名称 | 本项目来源 | 可做什么 | 不可做什么 |
|------|------|------------|----------|------------|
| **1** | 官方 | 食环署获准食肆名单；康文署宠物公园 / 宠物共享公园；渔护署负责任饲养等政策文件 | 硬过滤：准不准带狗进食肆、公园是否存在、法规问答 | 不能从官方名单推出菜系、商场准入或美容服务 |
| **2** | 场地自有 | `data/knowledge/mall_pet_policies.json`：各商场官网宠物守则 / 设施及服务 / 礼宾借用页 | 推荐商场时优先展示，并引用 `policy_url` | 不能当成政府统一「宠物友善商场名单」；不能推断该商场内所有店舖都欢迎宠物 |
| **3** | 社区 / 互补 | GoPaw `/api/venues`（学生项目获授权自取）；DogDogHK 商场目录；PetCircle 美容目录；OSM cuisine 标签；人工核实菜系 | 补缺口、扩大覆盖 | 不得覆盖 Tier 1/2；不得写成「官方确认」 |

查询排序：`mall_official` → `dogdoghk` / `petcircle` → `GoPaw`。重名时保留更高层级。

## 2. 授权与使用边界

| 来源 | 授权依据 | 使用边界 |
|------|----------|----------|
| FEHD | 公开政府名单 | 食肆「获准带狗」唯一硬来源 |
| LCSD | 公开设施资料 | 公园地点唯一硬来源 |
| 商场官网 | 公开发布的条款页 | 仅收录该页明确写出的规则 |
| GoPaw | 对方要求学生项目自行采集 `/api/venues` | 须保留书面/截图授权；目录作 Tier 3；菜系多为店名推断，匹配后才写入第二源 |
| DogDogHK | 公开网页目录 | 商场补缺，标注社区来源 |
| PetCircle HK | 公开网页目录 | 美容补缺，非渔护署持牌宠物店名单 |
| OSM | ODbL | 仅作菜系互补标签 |

渔护署持牌宠物店 PDF **不**当作美容主源：名单含售卖/用品店，且须资料当事人同意才公开。

## 3. 入库标准

### 商场进入 Tier 2

必须同时满足：

1. `policy_url` 落在商场自有域名（或集团商场站点，如恒隆 / 港铁商场）。
2. 页面含宠物守则、携带须知、设施及服务中的宠物条款，或明确的宠物车借用条款。
3. 摘要只复述该页内容；缺落地规则就写「请向礼宾确认」，不从博客补写。
4. 每条含：`name_en` / `name_zh`、地区、地址、`policy_url`、`access_mode`、`last_verified_at`。

博客、GoPaw、PetChill、Planto **不能**升为 Tier 2。

### 菜系「已确认」

- 食环署无菜系字段。
- 仅当第二源（OSM / 人工核实 / 匹配后的 GoPaw）实体匹配 ≥0.90，且 `cuisine_confidence` ≥0.70，才可过滤展示，并标明「非正式官方菜系」。
- 否则回答 **无法确认**，询问是否改查该区获准带狗食肆，**不得**列出未匹配名单当推荐。

### 诊所 / 美容

- 诊所：目前以 GoPaw `vet` / `dental` / `emergency` 为 Tier 3。
- 美容：PetCircle 优先，GoPaw 补缺口；均为 Tier 3。预订前须自行确认服务。

## 4. 期中验收题库标准

文件：`tests/test_acceptance_bank.py`。离线、`PAWPLAN_FORCE_DEV=1`、不调用付费模型。

| 类别 | 最低题数 | 通过条件 |
|------|----------|----------|
| 知识问答 | 4 | 调用 `search_knowledge`；回复含来源 + 核实日期 + URL |
| 领域过滤 | 3 | `tool_trace` 为空；点明超出范围 |
| 获准食肆 | 3 | 按地区检索；含 FEHD 来源；无菜系参数 |
| 菜系无法确认 | 2 | 传入 `cuisine`；无法确认则询问改查；不把未匹配店当点心/西餐推荐 |
| 公园 | 3 | `search_parks`；含来源与核实日期 |
| 商场 | 1 | `search_places` + `place_type=mall`；优先官网或标明社区来源 |
| 诊所 | 1 | `place_type=clinic` 或 `vet` |
| 美容 | 1 | `place_type=groomer` |
| 无结果 / 缺地区 | 3 | 明确暂无或追问地区；不编造 |

**通过定义：** `python -m unittest tests.test_acceptance_bank -v` 全部 OK。

## 5. 回复措辞标准

- Tier 1：可写「食环署获准名单」「康文署公园资料」。
- Tier 2：写「商场官网宠物政策」，并给出 `policy_url`。
- Tier 3：写「社区目录 / 互补来源」，提醒出发前再确认。
- 食肆内是否可带狗进某一档口：仍以 FEHD + 该店守则为准，商场友好不等于全场餐厅友好。
